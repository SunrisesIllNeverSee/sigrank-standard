# RFC-0001: RFC Process Template

## Status

Accepted

## Summary

This RFC establishes the process for proposing changes to the SigRank Standard.

## Motivation

The SigRank Standard needs a transparent, versioned change process that distinguishes draft proposals from accepted specification changes.

## Process

1. **Submit** — Open an RFC file in `rfc/` named `RFC-XXXX.md` using the template below.
2. **Discuss** — Public discussion in GitHub Issues or PR comments.
3. **Draft** — Author updates the RFC based on feedback.
4. **Implement** — Reference implementation and conformance fixtures are updated.
5. **Test** — Conformance suite passes with the new fixtures.
6. **Accept/Reject** — Owner decision recorded in the RFC status field.
7. **Release** — Accepted changes are versioned and released per the changelog.

## RFC Template

```markdown
# RFC-XXXX: Title

## Status
Draft | Accepted | Rejected | Withdrawn

## Summary
One paragraph.

## Motivation
Why this change is needed.

## Specification
The proposed change.

## Compatibility
What breaks and what is preserved.

## Fixtures
New or updated conformance fixtures.

## References
Links to related discussions, issues, or external standards.
```
